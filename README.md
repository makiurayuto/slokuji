# スロくじ

iPhone 向けの、スロット形式の箱くじアプリ（PWA）です。
Safari からホーム画面に追加でき、一度開いたあとは電波がなくても使えます。

- 公開先：<https://makiurayuto.github.io/slokuji/>
- 抽選・演出・記録はすべて端末の中で完結します（サーバー・ログイン・有料サービスなし）

## くじの中身

| 景品 | 本数 | 絵柄 |
|---|---:|---|
| 当たり | 11本 | 当 |
| 大当たり | 6本 | 大 |
| 特大当たり | 3本 | 特 |
| ラッキーセブン | 1本 | 7 |

- 合計21本。はずれなし。引いたくじは戻さない（箱くじ方式）
- **17回目は必ずラッキーセブン**。それ以外の回は、残っている当・大・特のくじ1本ずつが等しい確率
- 21回引き終えると「終了」。リセットで最初に戻る

## スロットの決まりごと

- 3段×3列。判定するラインは横3本と斜め2本（縦は判定しない）
- 中の列が止まった時点で、リーチ（左と中が同じ絵柄のライン）が2本以上あり、**リーチの絵柄はすべて別の種類**
- 右の列が止まると、当たった景品の絵柄で**ちょうど1本だけ**揃う。ラッキーセブンは真ん中の段で揃う
- 抽選結果を先に決めて保存してから、リールを回す（演出で結果が変わることはない）

## iPhone で使う

### ホーム画面に追加する

1. iPhone の **Safari** で <https://makiurayuto.github.io/slokuji/> を開く
2. 画面下の共有ボタン（四角から上向き矢印）をタップ
3. 「**ホーム画面に追加**」→「追加」
4. ホーム画面の「スロくじ」アイコンから開く

> **注意：Safari のタブで引いた記録と、ホーム画面のアプリの記録は別々です。**
> ホーム画面に追加してから使い始めてください。

### オフラインで使えるか確かめる

1. ホーム画面のアプリを開き、看板の左のランプが **緑で「オフラインOK」** になるのを待つ
2. アプリを完全に終了する（下から上にスワイプして止め、アプリを上にはじく）
3. iPhone を**機内モード**にする
4. ホーム画面のアプリを開く → 画面が出て、START で引ければ成功
5. 機内モードを戻す

ランプの意味：緑「オフラインOK」＝準備完了／黄の点滅「準備中」＝ファイルを保存中／灰色「オフライン不可」＝HTTPS 以外で開いている（例：PC から `http://192.168.x.x:8080` で開いたとき）

### 記録（残数・履歴）について

- 記録は **iPhone の中（このアプリの保存領域）** にだけ保存されます。ほかの端末とは共有されません
- 次の操作をすると記録が消えることがあります
  - ホーム画面からアプリを削除する
  - 「設定」→「アプリ」→「Safari」→「履歴とWebサイトデータを消去」
  - iPhone の空き容量が極端に少ないとき（iOS が自動で整理する場合）
- アプリの更新やオフライン対応で記録が消えることはありません
- 保存に失敗したときは抽選せず、メッセージ欄にエラーを表示します（もう一度 START を押せば引けます）
- 保存データが壊れていた場合は説明の枠が出ます。壊れたデータは消さずに端末内に退避し、「リセット」で最初からやり直せます

### 画面の操作

- **START**：1回引く（回転中・当選表示中は押せない）
- 当選表示は**画面のどこかをタップ**すると閉じる
- **音**：効果音の ON／OFF（最初は OFF。iPhone が消音モードだと鳴らないことがあります）
- **リセット**：確認のあと、回数・残数・履歴を最初に戻す（速さと音の設定は残る）
- **速さ**（右下）：リールが止まる速さ（遅い／普通／速い）
- **履歴**：「○回目 景品名」の一覧（右リールが止まってから追加される）
- 演出の途中でアプリを閉じても、次に開くと同じ結果がすぐ表示されます（引き直しにはなりません）

## 開発（Windows の PC）

必要なもの：Node.js 24 以上、Microsoft Edge（総点検とアイコン作りに使用）。外部のパッケージはありません（`npm install` は不要）。

| コマンド | 内容 |
|---|---|
| `npm start` | 確認用サーバーを起動（<http://localhost:8080>）。同じ Wi-Fi の iPhone からは表示される `http://192.168.x.x:8080` で開ける（この場合オフライン機能は動かない） |
| `npm test` | 自動テスト（抽選・盤面・保存・オフラインのファイル一覧）。先に sw.js の版の番号を自動更新する |
| `npm run check` | ブラウザでの総点検（Edge を画面なしで起動して操作する） |
| `npm run build` | 公開するファイルだけを `_site/` に集める（GitHub Actions でも同じことをする） |
| `npm run icons` | ホーム画面用アイコンを作り直す |
| `npm run stamp` | sw.js の版の番号だけを更新する |

> PC で `http://localhost:8080` を開くとオフライン用の仕組みが働きます。ファイルを変えたあとは
> `npm test`（版の番号の更新）→ タブを閉じて開き直す、で反映されます。

### ファイル構成

```
index.html / style.css / app.js   画面・見た目・動き
tiles.js                          絵柄（枠・波・王冠など）の描き方
logic/lottery.js                  抽選（箱くじ・17回目は7）
logic/board.js                    盤面づくり（リーチ・当選ライン）
logic/storage.js                  端末への保存と読み込み
sw.js                             オフライン用の仕組み（Service Worker）と保存するファイルの一覧
manifest.webmanifest              ホーム画面に追加するための設定
assets/                           絵柄の文字画像とアイコン
tests/                            自動テスト
tools/                            確認用サーバー・総点検・アイコン作り・公開用の集約など
.github/workflows/pages.yml       GitHub Pages への自動公開
```

### 絵柄の素材

- `assets/tou.png`・`dai.png`・`toku.png`・`seven.png`：元の写真（ChatGPT で作成した画像 `gatya.jpg`）から1文字ずつ切り抜いたもの。背景のごく薄い灰色は白に直してある
- 枠・波模様・王冠・光の線は `tiles.js` で描いている（画像ではない）
- `assets/icon-*.png`：`npm run icons` で「7」の絵柄から作ったアイコン
- 元の写真 `gatya.jpg` はアプリでは使わないため、Git の記録にも公開にも含めない

### 公開のしくみ（GitHub Pages）

- `main` に送る（push）と GitHub Actions が動き、**自動テスト → `_site/` に集める → 公開** の順に進む。テストに落ちたら公開しない
- 公開されるのは `sw.js` の一覧にある16ファイルと `sw.js` だけ（テスト・ツール・元の写真は含まない）
- iPhone 側は、新しい版を裏で受け取り、**アプリを一度終了して次に開いたとき**に切り替わる（記録はそのまま）

更新の手順：

1. ファイルを直す
2. `npm test`（版の番号が自動で更新される）と、必要なら `npm run check`
3. Git に記録して `main` に送る
4. GitHub の「Actions」タブで緑のチェックになれば公開完了

### 無料枠（2026年11月時点）

GitHub Free では公開リポジトリのみ Pages が使える。公開サイトは 1GB まで、通信量は月 100GB が目安（このアプリは約 0.4MB）。
参考：<https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits>
